# Contributing to kuririr


## Cara Berkontribusi
1. Fork repo ini.
2. Clone repo hasil fork.
3. Buat branch baru.
4. Install dependency:
mvn clean install
5. Tambahkan fitur atau perbaikan.
6. Jalankan test:
mvn test
7. Push dan buat Pull Request.


## Jenis Kontribusi
- Subcommand baru
- Perbaikan logika command
- Tambahan contoh penggunaan
- Peningkatan dokumentasi


## Aturan
- Gunakan gaya kode Java standar.
- Tambahkan test untuk fitur baru.
